Get Meta User Token

You need a User Token (starts with EAA…), not an App Token (app_id|secret).

Why Graph API Explorer fails

  • User or Page = App Token → cannot read ad accounts
  • Request path is empty (/v20.0/) → code 100 error
  • Token must be generated for app MCP_APP with ads_read

Step 1 — Add yourself to the Meta app

  1. Open Meta App Roles
  2. Add your Facebook account as Administrator or Developer
  3. In the app dashboard, add product Facebook Login if missing
  4. Ensure app mode is Development (fine for testing)

Step 2 — Generate token (easiest)

After login, copy the token from the redirect URL (#access_token=EAA…) or from Graph API Explorer.

Copied GROUND_TRUTH_ACCESS_TOKEN line

Step 3 — Test in Graph API Explorer

  1. Select Meta App: MCP_APP
  2. User or Page → your name (not App Token)
  3. Add permissions: ads_read, ads_management, business_management
  4. Query: me/adaccounts?fields=account_id,name,business{id,name}
  5. Submit — you should see account JSON

Step 4 — Restart connector

python ground_truth_mcp_server.py --http

Then open test-accounts.html
